# Настройка CineGram в отдельном репозитории

Это исходный код веб-интерфейса и приложений для macOS, Windows, Android, iPhone и iPad. Перед сборкой получите собственный ключ API метаданных Кинопоиска и задайте его в переменной окружения `CINEGRAM_KP_KEY`. Не записывайте настоящий ключ в исходники, Git, выпуски и журналы сборки. Если ранее используемый ключ был опубликован, замените его у поставщика API.

## Подготовка

Установите Node.js 24, затем в корне проекта выполните `npm ci` и `npm ci --prefix apps`. Для сборок iOS нужны macOS, Xcode и XcodeGen; для Android — Android SDK и Java. Задайте `CINEGRAM_KP_KEY` в окружении терминала безопасным способом до команд сборки или запуска.

- Веб-сервер: `npm start`. Ключ считывается при запуске сервера; после смены переменной перезапустите его.
- macOS/Windows для разработки: `npm --prefix apps run desktop`. Переменная должна быть доступна процессу запуска приложения; приложения, открытые из графического интерфейса, не обязательно наследуют переменные терминала.
- Android: `npm --prefix apps run prepare:android`, затем сборка Gradle по инструкции `apps/README.md`. При отсутствии ключа подготовка остановится с понятной ошибкой.
- iPhone/iPad: `npm --prefix apps run prepare:ios`, затем сборка Xcode по инструкции `apps/ios/README.md`. Для AltStore используется IPA с приложением в `Payload/`.

Для автоматических сборок настройте `CINEGRAM_KP_KEY` как секрет окружения CI и явно передайте его в шаг подготовки соответствующей платформы. Самостоятельно проверьте настройки всех workflow: локальные переменные терминала в GitHub Actions недоступны.

## Важно о ключе

Исключение ключа из исходников и использование секрета CI **не делает ключ секретным в готовом мобильном приложении**: Android и iOS встраивают его в свои ресурсы, и владелец APK/IPA сможет его извлечь. Не публикуйте такие сборки, если провайдер запрещает раскрывать ключ. Для настоящей защиты ключа нужен серверный посредник с защищёнными учётными данными либо ввод собственного ключа пользователем в приложении. Локальный сервер настольного приложения считывает ключ из окружения при запуске и не встраивает его при сборке.

Не добавляйте в Git каталоги сборок, `node_modules`, сгенерированные `WebAssets` и `AppConfig.java`, сертификаты, профили подписи, `.env`, ключи и локальные настройки SDK. Используйте новую историю репозитория без переноса старых коммитов с раскрытыми значениями.
